# Test models

All five files were downloaded with `scripts/download_models.sh` from the
collection by Alec Jacobson: <https://github.com/alecjacobson/common-3d-test-models>.
That collection gathers well-known test meshes; the original source of each is:

| File | Faces in file | Original source |
|---|---|---|
| `stanford-bunny.obj` | 69,451 triangles | Stanford 3D Scanning Repository, Stanford University Computer Graphics Laboratory (<http://graphics.stanford.edu/data/3Dscanrep/>) |
| `spot.obj` | 5,856 triangles | "Spot" the cow, by Keenan Crane (<https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/>) |
| `fandisk.obj` | 12,946 triangles | The Fandisk CAD model, a standard test part in mesh-processing papers (Hoppe et al.) |
| `suzanne.obj` | 500 polygons (968 triangles after splitting quads) | "Suzanne", the monkey head that ships with Blender (Blender Foundation) |
| `teapot.obj` | 6,320 triangles | The Utah teapot, Martin Newell, University of Utah (1975) |
